# Pulse8 Fitness

Premium gym website rebuilt with **Angular 22** (standalone components, signals, zoneless, lazy-loaded routes, reactive forms) and hand-written CSS.

Pages: Home (hero, facilities, plans), About, Gallery (lightbox), Join (membership form).

```bash
npm install
npm start        # http://localhost:4200
npm run build    # output in dist/pulse8
```

The original static HTML version lives in `legacy/`.
